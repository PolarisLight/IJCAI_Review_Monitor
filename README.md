# IJCAI_Review_Monitor
检测是否有改分

## 如何获取Reviewer ID

小红书挺多的，简单写一下
[cmt](https://cmt3.research.microsoft.com/IJCAI2025/Submission/ReViewsSnapshot/(你的论文编号)

刷新看f12每个作者的号码，记下来放到列表里面

同时保存cookies作为登录凭证
